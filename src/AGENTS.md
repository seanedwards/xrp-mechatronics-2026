# Source Guide

`src/` contains material delivered with or compiled into the robot project.

- Put executable Java robot code in `main/java`; follow `main/java/AGENTS.md` and its nested guides.
- Put robot deployment assets in `main/deploy`; follow `main/deploy/AGENTS.md`.
- Put automated tests in `test/java`, mirroring the production package structure when tests are added.
- Treat examples as teaching material: keep them runnable, straightforward, and commented line by line under the repository standard.
